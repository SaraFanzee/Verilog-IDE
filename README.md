# Verilog IDE

<img width="2560" height="1344" alt="总览" src="https://github.com/user-attachments/assets/7774a997-2078-446f-b011-c9329b8773a5" />


使用 Electron、Monaco、Yosys 和 slang 的 Verilog/SystemVerilog 桌面工作台。应用内置四态网表仿真器，打开后可直接综合自带的计数器与三态总线示例。

版本改动见[更新日志](CHANGELOG.md)。

## 使用

1. 解压适合当前系统的发行包。Windows 运行 `Verilog IDE.exe`，Linux x64 运行 `./verilog-ide`。
2. 启动时源码编辑器占满视图。新建、打开和保存源码的图标位于编辑器标题栏中。点击右侧的「综合」后编辑器占左侧四分之一，右侧显示电路和波形。拖动分界线可调整宽度，小三角可在隐藏、四分之一和全宽之间切换。直接综合示例，或打开自己的 `.v`、`.sv` 和头文件。实时语法检查和综合都会读取编辑器当前内容。首次综合默认生成「RTL行为级」电路图。在电路图标题栏切换到「门级」或切回「RTL行为级」时，应用按当前源码和设置重新生成所选层级。「综合」右侧的下拉按钮可打开综合设置。悬停在选项上可查看对应命令，也可逐行填写补充 Yosys 命令，在最终导出网表前执行。诊断与日志列出实际执行的脚本。综合设置可选择语言标准、顶层、参数、宏、包含目录、层级、优化及观察点保留。
<img width="767" height="402" alt="综合" src="https://github.com/user-attachments/assets/cc5883a6-e8aa-4346-a497-161d0a5da853" />

3. 在信号列表中选取波形，或右键点击电路图上的导线，将它添加到波形观察窗。波形观察列表中，点击名称前的「×」可移除信号，点击数值右侧的进制按钮可切换显示格式。信号列表的进制按钮、电路图中导线或端口数值的右键菜单也可设置进制，各视图同步更新。在电路图选中子模块可进入该层级。
<img width="739" height="440" alt="声明信号列表" src="https://github.com/user-attachments/assets/d2eac03e-d276-4a8f-a2bf-71472b04eab8" />

4. 在电路图单击一位输入可翻转，右键可指定 `X`、`Z` 或数值。多位输入支持二进制、十六进制、无符号十进制和补码有符号十进制。在电路图上的修改从应用时刻持续到再次修改或仿真结束。
<img width="741" height="555" alt="电路图点击输入" src="https://github.com/user-attachments/assets/de43a85c-8237-4e16-b2de-4f9ea8a0532e" />

5. 暂停时可以在波形图上同样编辑输入。默认覆盖该时刻所在的整周期，也可选择当前最小间隔或持续至结束。临时覆盖结束后恢复原定激励。回改历史会把仿真光标移到最早受影响时刻。编辑未来激励时，光标保持在原位置。
<img width="740" height="522" alt="波形图输入" src="https://github.com/user-attachments/assets/4895ab7a-645b-4682-a041-46fe2671e3be" />

6. 点击波形时间刻度可定位光标。每两个主刻度之间等分为十段。时间窗两端可分别拖动，拖动中间的色带可平移整个范围。时间轴也支持跟随光标。电路图中可用滚轮围绕指针缩放，用左键拖动视图。「适配」显示全图。
7. 电路图使用 ANSI/IEEE 91 常见逻辑门的特形符号、带时钟标记的寄存器和梯形选择器。导线采用正交布线，分支接点带圆点。可映射到网表的变量标注在对应的导线或寄存器附近。输入和时钟在最左列，输出在最右列。密集门级电路按连接关系分层，同层元件较多时分列排列。配色面板可分别调整输入、输出、双向端口和其他元件的边框与填充。

## 仿真约定

门级 `$_TBUF_` 与 RTL `$tribuf` 使用同一尺寸的三角形。悬停在三态缓冲器的常量端口名称或 MUX 的省略标签上，可查看完整的端口赋值。

按 `F11` 进入或退出全屏。使用 `Ctrl++`（或 `Ctrl+=`）、`Ctrl+-` 和 `Ctrl+0` 放大、缩小或还原整个界面。源码编辑器的右键菜单提供常用文本编辑操作。

多位总线的两侧带有边框，中央线色表示逻辑状态。在电路图的「配色」中可分别修改「总线边框」「关键路径」和「画布背景」，下次启动沿用所选颜色。布线完成后会反复简化折线、压缩空白，并在新布局上复查。

集线器和分线器画成一条粗竖线，左侧为输入，右侧为输出。已声明信号按源码名称和位序标注，例如 `src[3:2]`。以元件端口标识未声明信号时，写出实例名、端口名和位选，例如 `$procmux$50.B[14:0]`。`32×sel[0]` 表示将同一位复制 32 次，`32'b0` 表示 32 位全零。悬停在分支标签上可查看它与整条总线的位对应关系。悬停在导线或端口上可查看位宽、当前值和显示进制。

勾选电路图工具栏的「关键路径」可查看当前层级内总传播延迟最长的一条数据路径。所选的关键路径颜色标出经过的元件、引脚和导线分支，图例旁以同色显示总延迟。悬停在数值上可查看路径顺序。展开子模块后按该层级重新分析。修改元件延迟或最小间隔会更新结果。
<img width="1486" height="644" alt="关键路径" src="https://github.com/user-attachments/assets/000a04ba-9598-46a0-93d3-42b0a2d16363" />


路径从输入端口或存储元件输出开始，在输出端口或存储元件的数据、同步控制输入结束。发起路径的存储元件计入其输出延迟。总延迟按当前元件延迟之和乘以最小间隔估算，导线延迟与建立时间按零处理，锁存器按时序边界处理。等长时显示其中一条。影响终点的组合反馈会显示提示。

- 最小间隔以整数 ps 设置，默认 50 ps。时钟周期与结束时间使用 ns，默认分别为 1 ns 与 100 ns。时间设置会在停止输入片刻后自动生效，按回车或离开输入框也可立即生效。输入值无效时继续使用上一次有效设置。播放速度可在 1 到 100 ns/s 间调整，默认每秒推进 10 ns。时钟周期为最小间隔的正偶数倍，仿真范围最多 100,000 个间隔。修改最小间隔会重置激励。顶部周期用作整周期步进和波形整周期覆盖的时间基准，识别为时钟的端口可以另设周期。
- 普通输入默认低电平，双向外部驱动默认高阻，识别出的时钟从低电平开始。仿真默认应用元件延迟，可在「元件清单」单独调整，或使用「延迟全部清零」和「恢复默认」。修改延迟保留已添加的激励，并从零重新计算波形。
- 默认延迟按逻辑深度估算，以最小间隔为单位。例如反相器和与非门为 1，二输入与门、或门及基本触发器为 2，异或与二选一选择器为 3，加减为 4，宽选择器为 5，乘法为 8，除法为 12。这些值是通用相对估计。实际延迟还取决于映射工艺、位宽、负载和布线。延迟采用惯性模型，比延迟更短的脉冲可能被滤除。
- 仿真基于所选层级的综合网表。常用组合逻辑、三态、加减乘除、移位、多路选择器、触发器、锁存器和映射后的常见逻辑门可交互仿真。若自定义库、黑盒或某个映射元件缺少仿真模型，应用会报告具体元件类型。综合可能消除信号或改变含未知值的行为，应根据目标使用 RTL 或门级结果。
- Windows 与 Linux 发行包携带综合和语法检查工具。Linux 仍需要桌面图形会话和 Electron 所需的系统图形库。

## 构建和验证

每次发行前，在项目根目录的 `CHANGELOG.md` 顶部以 `## v版本号` 新增一节，按用户可见的变化记录本次实际改动。打包脚本按 `package.json` 的版本号提取该节，写入 Windows 和 Linux 发行包根目录的 `CHANGELOG.md`，并在压缩包旁生成独立的 `Verilog-IDE-版本号-更新日志.md`。同一版本的两个平台共用一份日志。可运行 `npm run release:notes` 单独生成当前版本的日志。

开发环境使用 Node.js 22 或更新版本。安装与目标系统匹配的 [OSS CAD Suite](https://github.com/YosysHQ/oss-cad-suite-build/releases)，确保包含带 `read_slang` 的 Yosys、独立的 slang 和 ABC。可将工具添加到 `PATH`，或设置 `VERILOG_IDE_TOOLCHAIN` 指向套件根目录。

```sh
npm ci
npm run typecheck
npm test
npm start
```

打包命令会校验 Electron 下载文件，在 `release/` 创建带工具链的压缩包。Windows 需要系统自带的 `tar.exe`。Linux 构建需要 `unzip`、`tar` 和 `curl`（若 Electron ZIP 未缓存）。也可在 Windows 上用原生 Linux 工具链 tarball 交叉打包。

```powershell
npm run package -- --platform win32 --toolchain C:/HDLTools
```

```sh
npm run package -- --platform linux --toolchain /opt/oss-cad-suite
```

```powershell
npm run package -- --platform linux --toolchain-archive runtime/oss-cad-suite-linux-x64.tgz
```

桌面集成测试执行 `npm run build` 后，可用 `node_modules/.bin/electron test/electron-smoke.cjs` 运行。它检查实际桌面窗口中的编辑器、实时检查、综合、电路图输入交互、周期步进和历史激励回改。
